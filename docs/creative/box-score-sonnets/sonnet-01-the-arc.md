# Sonnet I: The Arc

Two point five attempts from downtown each night,  
The eighties played inside, the post supreme.  
Three-five is now the league's relentless flight,  
The arc has reimagined every scheme.  

Point two-seven-three, the early splashing rate,  
Point three-six-four, the modern sharpened eye.  
The paint once ruled with pivot and with weight,  
Now spacing pulls defenders to the sky.  

One hundred nine the decade's scoring mean,  
Both eighties and the twenties share that score.  
Yet how the points arrive has changed the scene:  
Fourteen more threes per game than years before.  

The arc bends history with every swoosh,  
The game's geometry: a three-point push.
