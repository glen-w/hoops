## 2. Mid-Level Exception — still Article VII?

**Yes.** In both editions the MLE trio lives under **Article VII, Section 6**, letters **(e)(f)(g)**:

| Variant | 2017 | 2023 |
|---------|------|------|
| Non-Taxpayer Mid-Level Salary Exception | `cba:2017:art-VII:sec-6:(e)` | `cba:2023:art-VII:sec-6:(e)` |
| Taxpayer Mid-Level Salary Exception | `cba:2017:art-VII:sec-6:(f)` | `cba:2023:art-VII:sec-6:(f)` |
| Mid-Level Salary Exception for Room Teams | `cba:2017:art-VII:sec-6:(g)` | `cba:2023:art-VII:sec-6:(g)` |

Always qualify cites with `edition_id` — the letter layout can stay put while §12 / §2 meaning drifts.

## 10. Writer takeaway

1. **MLE is still Art VII §6 (e)(f)(g)** in 2017 and 2023 — cite `cba:<year>:…`.
2. **VII §12 is not stable** across editions (Escrow/Tax vs Designated Share).
3. **Apron / Tax Level** appear in the 2023 Art VII title and §2; 2017 title is escrow-forward.
4. Exhibit **B** encoding differs (B-1/B-2/B-3 vs single B).
5. Prefer this file + per-edition `structure.json` over memory for multi-era cites.
