# League income ingredients — source map

**Access date:** 2026-09-19  
**Mode:** Design map for a "where does the money come from?" box. Not a BRI audit.

## Conceptual stack (writer-facing)

Use CBA language carefully once parser exists (`Basketball Related Income`, Audit Report, etc.). Until then, label as **industry reporting**, not contractual BRI.

Suggested ingredients for a schematic (not exhaustive):

| Ingredient | Typical public discussion | Notes |
|------------|---------------------------|-------|
| National media rights fees | ESPN/ABC, TNT (through 2024–25); then Disney / NBC / Amazon (2025–26+) | League distribution to teams; drives cap |
| Local media | RSNs / local streaming substitutes | Team-skewed; valuation-relevant |
| Gate / ticketing | Arena live gate | ~$1.5B leaguewide cited in older SBJ color |
| Team + league sponsorship | Jersey patches (from 2017–18), league sponsors | Patch revenue split / sharing rules → CBA |
| Other BRI-ish | NBA TV, international, events, … | Details are contractual |
