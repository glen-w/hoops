# CBA structure metadata

Committed article, section, and exhibit indexes for the 2017 and 2023 agreements. No agreement text. The PDFs stay in gitignored `data/raw/cba/`.

Lookup and the chapter map read this tree: `data/cba/<edition>/derived/`.

`data/derived/cba/` is an older extractor fixture (`2023/structure.fixture.json`). The JSON shape there is not this index. Do not treat the two trees as copies.
